# Code of Conduct

## Our Standard

CseGraph is a developer tool project. Contributors are expected to keep
discussion focused, technical, and respectful.

Examples of expected behavior:

- Use welcoming and inclusive language.
- Assume good intent while asking for evidence and clear reproduction steps.
- Critique ideas, code, and tradeoffs rather than people.
- Respect maintainers' scope decisions for the `csegraph` package, CLI, MCP
  server, and VS Code extension.

Examples of unacceptable behavior:

- Harassment, insults, threats, or discriminatory language.
- Publishing private information without explicit permission.
- Repeatedly derailing issues or pull requests after a maintainer decision.
- Abusive or disruptive conduct in project spaces.

## Enforcement

Report conduct concerns privately through GitHub Security Advisories or by
contacting the repository maintainers through GitHub. Maintainers may remove
comments, close issues, restrict participation, or block accounts when needed
to keep project spaces usable.

Maintainers will review reports in context and aim to respond within seven
days. Good-faith reports will be handled confidentially where possible.
