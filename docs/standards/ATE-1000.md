# ATE-1000: Agent Token Economy (internal)

ATE-1000 governs internal and database-facing text that users do not see:
stored lexical summaries, internal metadata JSON, occurrence candidate lists,
and other persistence-layer strings.

## Rules

1. Store whitespace-normalized, filler-free summaries. Keep signatures, symbol
   names, paths, and language keywords exact.
2. Serialize internal JSON canonically: sorted keys, no insignificant spaces.
3. Do not store display-only prose, empty defaults, or repeated fields.
4. Keep one internal summary per node. Prefer compact bullets over sentences.
5. Target 1000 bytes of stored prose per row; preserve the tokens retrieval
   needs (names, signatures, paths) before trimming anything else.

## Implementation

`csegraph._core.text.compression.compact_internal` normalizes stored summaries.
`compact_json` writes canonical internal JSON. Summaries are compacted in the
ingestion layer, and internal JSON uses the compact serializer in indexing,
resolution, and freshness metadata.

The 1000-byte target does not truncate signatures or identifiers. Summary
compression applies only to prose; signatures, names, bases, and calls retain
their original text.
