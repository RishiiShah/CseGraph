# v1.8.0 vs v2.0.0 Sandbox Benchmark

This report compares the canonical `auto` sandbox benchmark profile from
CseGraph `1.8.0` against the current `2.0.0` build on the same 10 repositories.

The key change from the earlier draft is that the `django` lease problem is now
fixed. The current run completes `django` successfully, so the numbers below
measure the actual refresh cost instead of a skip.

## Summary

| Metric | v1.8.0 | v2.0.0 | Change |
|--------|-------:|-------:|-------:|
| Aggregate chars/4 reduction | 299.8x | 18,537.7x | 61.8x larger |
| Aggregate OpenAI proxy reduction | 280.7x | 15,959.3x | 56.8x larger |
| Avg MCP latency | 1,118.4 ms | 139.4 ms | 8.0x faster |
| Avg Phase B total | 15,748.2 ms | 9,724.4 ms | 1.6x faster |

## What Improved

- Token reduction improved dramatically on every repository.
- `pandas`, `transformers`, `scikit-learn`, `fastapi`, `celery`, and `pytest`
  all moved into a much faster runtime band than `1.8.0`.
- The `django` lease bug is fixed, so the benchmark now measures the real
  refresh path instead of a skip.

## What Regressed

- `nanoGPT`, `micrograd`, and `flask` are slower on latency than `1.8.0`.
  These workloads are small enough that fixed overhead dominates.
- `django` now completes successfully, but that successful refresh is much
  more expensive than the old `1.8.0` run.

## Fix Status

The lease failure itself is fixed in `2.0.0`. The remaining work is performance
tuning, especially for the tiny repositories where constant overhead dominates.
